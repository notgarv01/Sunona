# 🎵 SunoNa!! - Modern YouTube Music Desktop Client

<p align="center">
  <strong>A modern, frameless YouTube Music desktop client with Spotify aesthetic, synchronized lyrics, Indian charts, and personalized AI automix.</strong>
</p>

---

## ✨ Features

- **Spotify Frameless Window**: Clean, borderless desktop window with integrated caption controls and drag region.
- **Laptop Hardware Media Keys**: Control Play/Pause, Next Track, and Previous Track directly from your laptop keyboard even when minimized.
- **YouTube Music Streaming Engine**: High-fidelity audio streaming with HTTP Range headers for instant seek & zero buffering.
- **Synchronized Lyrics (Karaoke)**: 5-stage multi-source lyrics waterfall engine (LRCLIB, Genius, lyrics.ovh).
- **Curated Indian Charts & Moods**: Bollywood Hot 50, Late Night Lofi, Punjabi Pop, Desi Hip-Hop, and Mood Soundscapes.
- **AI Recommendations & Daily Mixes**: 4 Daily Mixes tailored to your taste profile, plus "Similar To..." live auto-recommendations.
- **Persistent Liked Songs & Playlists**: Save and manage your favorite tracks with instant local persistence.
- **Sleep Timer & Ambient Mode**: Gradual volume fade-out sleep timer with custom ambient soundscapes.
- **Listen Together (Room Sync)**: Real-time multi-listener room sync with chat.

## 💻 Development & Building Locally

```bash
# Clone the repository
git clone https://github.com/notgarv01/Sunona.git
cd Sunona

# Install dependencies
npm install

# Start Vite development server
npm run dev

# Start Electron in development mode
npm run electron:dev

# Build Windows Installer (.exe)
npm run electron:build
```

## ⌨️ Laptop Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Space` | Play / Pause |
| `Ctrl + →` / `Media Next` | Next Track |
| `Ctrl + ←` / `Media Prev` | Previous Track |
| `Ctrl + K` / `/` | Open Search |
| `Ctrl + L` | Toggle Liked Song |
| `M` | Mute / Unmute |
| `L` | Toggle Lyrics Drawer |
| `Q` | Toggle Up Next Queue |
